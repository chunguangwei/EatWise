# 《明食 · EatWise — 规格：i18n 中英双语规范》v1.0

> 决策锚点：**D-15**（MVP 即支持简体中文 + 英文双语；默认跟随系统，设置内可手动切换；文案全部走 i18n key，禁止硬编码；社区 UGC 不分语言圈）。
> 关联决策：D-04 / D-05（营养目标与信号灯建议双语模板）、D-09（本地通知双语文案）、D-13（登录方式，iOS 强制 Sign in with Apple）、D-14（iOS 15+ / Android 8.0+）、D-16（食物库双语条目）、D-17（Flutter + slang/intl）、D-18（隐私政策与免责声明双语）。
> 状态标注：`〔假设〕` = 本规格补充的合理推断；`〔待外部确认〕` = 上线前需外部书面确认。

## 一、语言策略

### 1.1 语言决策规则

| 优先级 | 规则 | 说明 |
|--------|------|------|
| 1 | 用户在设置内手动选择过语言 | 以 `User.languagePreference` 为准（`zh-CN` / `en`） |
| 2 | 未手动选择（默认 `system`） | 跟随系统语言：系统为中文（zh-Hans/zh-Hant 任意地区）→ `zh-CN`；其余 → `en` |
| 3 | 兜底 | 任何解析失败 → `zh-CN`（D-15 上架区域：MVP 中国区为主） |

- `languagePreference` 取值：`system`（默认）/ `zh-CN` / `en`，共三态；展示层只有两个有效语言 `zh-CN`、`en`。
- **切换即时生效，无需重启 App**：语言为全局响应式状态（Riverpod `StateProvider`），切换后全树重建文案；已入队的本地通知按新语言重新调度（见 3.3）。
- MVP 仅两种语言，但 i18n 框架（slang）本身支持后续追加 locale，新增语言不得改动 key 结构。

### 1.2 User 实体扩展与云端同步

`User` 实体新增字段（对 PRD 第五章数据模型的补充）：

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `languagePreference` | `enum('system','zh-CN','en')` | `system` | 随账号云端同步，换机/重装后恢复 |
| `weightUnit` | `enum('kg','lb')` | 随语言初始化：zh→`kg`，en→`lb`〔假设〕 | 见 5.3，独立设置项，不随语言强制联动 |

- 同步遵循 D-20：本地优先 + 字段级 LWW（以服务端时间戳为准）；语言切换立即本地生效，异步上行，不阻塞 UI。
- 未登录（游客态）：`languagePreference` 仅存本地，登录后若云端已有值且本地从未手动设置过，以云端为准；本地手动设置过则以本地为准（视为更新写入）〔假设〕。

### 1.3 双端实现要点

| 项 | iOS（15+，D-14） | Android（API 26+，D-14） |
|----|------------------|--------------------------|
| 系统语言读取 | `PlatformDispatcher.locale`，无需声明 | 同左；Android 13+ 若启用 per-app language，需在 `AndroidManifest` 声明 `android:localeConfig`，否则用户经系统设置改语言与本 App 内设置可能不一致 |
| 切换生效 | Dart 层重建即可；已调度的 `UNUserNotificationCenter` 通知需按新语言取消重排 | 同左；`flutter_local_notifications` 已排期通知需按新语言取消重排 |
| 字体 | 系统自带苹方（PingFang SC），无需打包 | 需内置思源黑体（Noto Sans SC）或指定回退链，见 6.4 |

## 二、文案管理

### 2.1 技术方案（D-17）

- 框架：**slang**（类型安全、编译期校验缺失翻译）为主，日期/数字/复数格式化用 `intl`。
- 源文件：`i18n/strings_zh-CN.i18n.json`（主语言，开发以中文为源）+ `i18n/strings_en.i18n.json`；缺译时回退主语言并在 CI 报警。
- **禁止硬编码**：Dart 代码中不得出现面向用户的字符串字面量；CI 增加 lint 规则扫描硬编码中文/英文文案（白名单：日志、断言、key 名）。信号灯建议、通知文案等由规则引擎输出的字符串，一律从 i18n key 取模板渲染（D-05）。

### 2.2 key 命名规范

格式：`模块.页面.元素[.变体]`，全小写驼峰，变体用于同元素的形态区分。

```
<module>.<page>.<element>[.<variant>]
```

| 段 | 取值约定 | 示例 |
|----|----------|------|
| 模块 | `onboarding` `fasting` `record` `nutrition` `community` `settings` `common` `notification` `fun` `legal` | `fasting` |
| 页面 | 页面或子功能标识 | `home`、`timer`、`signalCard` |
| 元素 | 语义化元素名，禁止位置命名（`leftButton` ❌） | `endFast`、`streakBadge` |
| 变体 | 状态/落区/餐段等 | `protein.yellow.dinner` |

示例：

| key | zh-CN | en |
|-----|-------|----|
| `fasting.home.endFast` | 结束断食 | End fast |
| `fasting.home.extend` | 延长 | Extend |
| `nutrition.signalCard.advice.protein.yellow.dinner` | 今天蛋白质有点少🟡 晚餐加个鸡蛋就够啦 | Protein's a bit low today 🟡 An egg at dinner will do it |
| `notification.fasting.windowStart` | 断食窗口开始啦，今天也很棒，加油坚持～ | Your fasting window has started — you're doing great, keep it up! |
| `fun.empty.recordPage` | 肚子的故事还没写呢，点橙色按钮记一笔？ | No food stories yet — tap the orange button to log your first bite? |
| `common.action.undo` | 撤销 | Undo |

规则：
- 带参数的文案用占位符，禁止字符串拼接：`notification.streak.milestone` → 中文「连续 {days} 天！你已经超过了 {pct}% 的伙伴 🎉」/ 英文「{days} days in a row! You've outlasted {pct}% of the community 🎉」。占位符顺序中英可不同，slang 参数化天然支持。
- 复数（如「N 天连胜」「待同步 N 条」）用 intl plural，英文 one/other，中文仅 other。
- 品牌名「明食 · EatWise」不译，两种语言均保持「明食 · EatWise」出现在关于页；其余界面统一用「EatWise」〔假设〕。

### 2.3 品牌语气中英对照原则（承接设计稿 2.4）

原则三句话：**鼓励而非命令（Encourage, don't command）｜简单而非术语（Simple, not clinical）｜真诚而非营销腔（Sincere, not salesy）**。英文不是逐字翻译，而是同一语气下的地道重写：用第二人称、现在时、短句；允许轻度拟人与 emoji，与中文版本等量，不过度夸张。

五组对照示例：

| 场景 | zh-CN | en | 语气要点 |
|------|-------|----|----------|
| 引导 | 3 个小问题，帮你找到最适合的断食节奏 🌱 | 3 quick questions to find the fasting rhythm that fits you 🌱 | 「帮你」→「that fits you」，邀请而非推销 |
| 断食提醒 | 断食窗口开始啦，今天也很棒，加油坚持～ | Your fasting window has started — you're doing great today, keep it up! | 肯定已发生的努力，不施压 |
| 营养反馈 | 今天蛋白质有点少🟡 晚餐加个鸡蛋就够啦 | Protein's a bit low today 🟡 An egg at dinner will do the trick | 给出具体、可执行、低成本的建议 |
| 打卡激励 | 连续 7 天！你已经超过了 80% 的伙伴 🎉 | 7 days in a row! You've outlasted 80% of the community 🎉 | 庆祝事实，不制造焦虑比较 |
| 避免的反例 | ❌ 您的每日蛋白质摄入量低于 RDA 推荐值 23% | ❌ Your daily protein intake is 23% below the RDA | 术语堆砌、居高临下、无可执行指引，中英均属禁用语气 |

禁用清单（中英通用）：医疗术语直译（RDA/TDEE 出现在用户可见文案）、命令式（「必须」「You must」）、制造羞耻/焦虑（「你又超标了」「You failed」）、营销夸张（「奇迹」「miracle」）。

## 四、食物库双语（D-16）

### 4.1 条目结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 全局唯一 |
| `name_zh` | string | 中文标准名（如「鸡胸肉」） |
| `name_en` | string | 英文标准名（如「Chicken breast」） |
| `aliases_zh` | string[] | 中文别名/俗称（如「鸡大胸」「鸡脯肉」） |
| `aliases_en` | string[] | 英文别名/拼写变体（如「chicken breasts」「grilled chicken breast」） |
| 营养字段 | number | 每 100g 热量 kcal / 蛋白 g / 碳水 g / 脂肪 g（单一数值，不分语言） |
| `category` | enum | 分类，展示名走 i18n key（`record.category.*`） |

MVP 规模 ≥3000 条高频食物（《中国食物成分表》+ USDA FDC 清洗合并，D-16）。

### 4.2 双语搜索规则

1. 搜索词同时与 `name_zh / aliases_zh / name_en / aliases_en` 四组字段匹配，**与当前界面语言无关**——中文界面输 "chicken" 能搜到鸡胸肉，英文界面输「鸡胸」同样能搜到。
2. 匹配优先级：当前语言的 name 精确 > 当前语言别名前缀 > 另一语言 name/别名 > 模糊（拼音/子串）〔假设：拼音匹配为 V1.1 候选，MVP 仅子串模糊〕。
3. 结果展示名按当前语言取 `name_zh` 或 `name_en`；若某条目缺失当前语言名称（数据未覆盖），回退另一语言名称并在条目右上角标小字原文，不得留空〔假设〕。
4. 排序：匹配优先级 > 用户历史频次（常吃复用权重）> 全局热度。

### 4.3 识别结果展示

- 拍照识别（第三方 API）与语音识别（系统 ASR + 词典匹配，D-16）返回的是食物库 `id`，**不返回展示字符串**；UI 按当前语言渲染 `name_zh/name_en`。
- 置信度低标记「请确认 / Please confirm」等提示走 i18n key（`record.confirm.*`）。
- 语音 ASR：中文界面用中文 locale 识别、英文界面用英文 locale 识别；识别出的文本经食物库双语词典匹配（双语别名均在匹配词典内）。

## 五、本地化格式

### 5.1 日期

| 场景 | zh-CN | en | 实现（intl） |
|------|-------|----|--------------|
| 一般日期 | X月X日（7月27日） | MMM d（Jul 27） | `DateFormat.Md(locale)` |
| 带星期 | X月X日 周X（7月27日 周一） | EEE, MMM d（Mon, Jul 27） | `DateFormat.E().add_Md()` 中文环境自定义拼接 |
| 带年份（跨年/历史） | X年X月X日 | MMM d, yyyy | `DateFormat.yMMMd(locale)` |
| 归属日文案（评审项 1） | 本次断食计入 7月27日 | This fast counts toward Jul 27 | key：`fasting.home.attribution`，日期参数格式化 |

### 5.2 时间制式

- **跟随系统 12/24 小时制设置**，不按语言硬绑：中文用户也可能用 24 小时制，英文用户也可能用 12 小时制。实现：`MediaQuery.alwaysUse24HourFormat` + `DateFormat.jm/Hm` 自适应。
- 进食窗口展示示例：zh 24h「12:00–20:00」；en 12h「12:00 PM – 8:00 PM」。
- 倒计时（HH:MM:SS）纯数字，无语言差异。

### 5.3 数字与单位

| 项 | 规则 |
|----|------|
| 热量 | `kcal` 不译，中英均写 kcal；千分位按 locale（1,800 kcal 两种语言同形，中文不强制空格） |
| 宏量营养素 | `g` 不译（蛋白 24 g）；展示不写「克」 |
| 体重 | 可选设置项 `weightUnit`：`kg` / `lb`，默认随语言初始化（zh→kg，en→lb）〔假设〕，设置内可独立改；**存储层统一 kg**，仅展示层换算（1 lb = 0.45359237 kg，展示保留 1 位小数） |
| 数字格式 | 走 intl `NumberFormat.decimalPattern(locale)`；营养数值用 Inter 字体（设计稿 2.3） |

## 六、布局适配

### 6.1 文案长度膨胀

英文相对中文普遍膨胀 **30–40%**（按钮短词可能达 100%+，如「延长」→「Extend」）。规则表：

| 组件 | 规则 |
|------|------|
| 按钮 | 最小宽度 88px〔假设〕，文案超长时先缩字号一档（16→14），仍超长允许换行（最多 2 行），禁止截断按钮文案；「结束断食 / 延长」双按钮横排在英文下放不下时改为上下堆叠〔假设〕 |
| Tab 栏 | 标签最多 1 行，超长截断加省略号；英文 Tab 名用短词（Home / Log / Data / Social / Me）〔假设，待设计确认〕 |
| 卡片一句话建议 | 最多 2 行，超出截断「…」，点击展开全文〔假设〕 |
| 信号灯卡数值 | 数值用 Inter，禁止截断；单位换行降级 |
| 通知 | 系统通知正文天然截断，关键信息（时间、动作）放句首 |

全局原则：**宁可换行，不截断语义**；截断仅限 Tab、列表标题等明确允许的位置，且须有省略号。

### 6.2 走查基线

- 每个页面以英文 + 系统字号 200%（M8 硬性要求）双压力组合走查：英文长文案与大字号叠加是截断高发场景。
- 断食倒计时 48px Inter Bold 数字无语言差异；状态文案（断食中 / Fasting）在环心预留 2 行空间〔假设〕。

### 6.3 字体回退链

| 语言/内容 | iOS | Android |
|-----------|-----|---------|
| 中文 | PingFang SC（系统自带） | 内置 Noto Sans SC（思源黑体），回退系统默认 |
| 西文与数字 | Inter（内置打包），回退 SF Pro | Inter（内置打包），回退 Roboto |

- 设计稿基准：中文 思源黑体/苹方，西文数字 Inter。Flutter `TextStyle.fontFamilyFallback: ['Inter', 'PingFang SC', 'Noto Sans SC']`，中英混排时数字自动落 Inter，中文落苹方/思源。
- Inter 与 Noto Sans SC 需随包内置（Android 中文不可依赖系统），注意字体包体积，按字重裁剪子集〔假设〕。

## 七、社区 UGC 语言策略（D-15）

- MVP **不分语言圈**：打卡流全量混排，中文用户可见英文打卡，反之亦然；V1.1 再评估分流。
- UGC 正文**不提供机器翻译**（MVP 范围外）〔假设〕。
- UI 壳层（按钮、徽章、互动计数标签、举报/审核提示）照常双语。
- 内容审核（D-17 第三方内容安全 API）需同时覆盖中英两种语言的文本审核〔待外部确认：供应商多语言审核能力，M0 选型时确认〕。
- 里程碑徽章文案（「7 天连胜 🔥」等）为系统生成内容，按发布者当前语言渲染；分享图卡上的文案同样按发布者语言生成〔假设〕。

## 八、验收清单（双语言走查 Checklist）

每次发版前对 zh-CN 与 en 各走查一遍，全部通过方可提审：

| # | 检查项 | 通过标准 |
|---|--------|----------|
| 1 | 无硬编码残留 | CI lint 扫描通过；两语言下逐页检查无「另一语言残留文案」（中文界面无英文句、英文界面无中文句，品牌名/kcal/g 等豁免） |

| 4 | 通知双语 | 两种语言下窗口提醒（前 15 分钟 + 到点，D-09）通知标题/正文均为当前语言；切换语言后重新调度的通知为新语言 |
| 5 | 空状态/加载态/彩蛋双语 | `fun.*` 全部条目两种语言均有非空翻译，无回退残留 |
| 6 | 信号灯建议双语 | 4 营养素 × 3 落区模板中英齐全，占位符渲染正确，语气符合 2.3 原则 |
| 7 | 日期/时间/数字格式 | 中文「X月X日」、英文「MMM d」；12/24 小时制跟随系统；千分位与单位正确；体重 kg/lb 切换换算正确 |
| 8 | 食物库双语 | 双语言搜索互查命中（中文搜 chicken、英文搜鸡胸）；识别结果按当前语言展示；缺译条目有回退而非空白 |
