## 四、踩坑档案（本周全部实战教训）

### 4.1 环境类（换机必读）
1. **中文路径三杀**：① `flutter analyze` 在中文路径崩溃 → 用 `dart analyze`；② Gradle 读 `local.properties` 的 `flutter.sdk` 按 ISO-8859-1 解码中文乱码 → settings.gradle.kts 已改 UTF-8 逐行解析 + gradle.properties 强制 JVM UTF-8；③ SDK 内 `FlutterAppPluginLoaderPlugin.kt` 同问题已打补丁（.tooling 不入库，**重装 SDK 需重打**，补丁内容见 git 历史或重新按 AGENTS.md 说明处理）
2. **Android 构建**：系统 Java 11 不行，必须 JBR 17+；`jni` 包 1.0.1 与 AGP 9 不兼容（lock 已升 1.0.2）；`flutter_local_notifications` 需 core desugaring（已配）；国内依赖下载卡死 → `USE_CN_MIRRORS=1`（CI 海外 runner 不可开）
3. **iOS**：部署目标已升 15.0；Xcode Accounts 无账号时签名报 "No Account for Team"；**debug 包不能从主屏幕启动**（iOS 14+ 限制），真机日用装 release
4. **模拟器**：访问宿主机后端用 `10.0.2.2` 不是 localhost；`API_BASE_URL` **必须含 /v1**（踩过 404 的坑）

### 4.2 框架/代码类
5. **Flutter 3.44 行为变更**：带 action 的 SnackBar 默认 `persist: true` 永不消失——所有限时吐司必须显式 `persist: false`（撤销吐司 bug 根因，有回归测试 `undo_toast_regression_test.dart`）
6. **slang**：`namespaces: false` 下同 locale 多 i18n 文件互相整份覆盖 → 全项目只有 `i18n/strings_zh-CN.i18n.json` / `strings_en.i18n.json` 两个文件；生成固定 `dart run slang`；`slang_build_runner` 已移除（它会让 build_runner 整体失败）
7. **drift 测试死锁**：流退订的内部 Timer 落 widget 测试假时钟区与 `db.close()` 互等 → 测试体内卸载+多次 pump，close 放 addTearDown（见 record 测试 settleUi 注释）
8. **点中率**：adb 盲 tap 坐标按 uiautomator bounds 取（`adb shell uiautomator dump`），截图显示会缩小勿按显示比例算

### 4.3 产品逻辑类（修复记录，回归测试已锚定）
