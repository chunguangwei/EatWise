# 薄荷健康对标合并设计 v1.0

> 输入：内部差距分析（onboarding/档案/体重/健康数据现状）+ 薄荷健康公开调研报告。
> 原则：薄荷是「通用体重管理平台」，EatWise 是「轻断食为核心的健康饮食 App」——只吸收能强化主线的能力，明确排除导致薄荷臃肿的部分。

## 二、阶段路线

- **阶段 A**（实施中）：onboarding 档案页（可跳过）+ computeNutritionGoal 全参接线 + PATCH /users/me + 服务端 onboardingStatus 修复 + 进食障碍筛查题
- **阶段 B**：schema 加 targetWeightKg/weeklyRateKg（安全上限 0.5–1kg/周）→ 速率→日缺口（7700 kcal/kg）→ targetKcal = TDEE − 缺口；推荐页展示「预计每周减 X kg」；规格文档同步 + 营养背书
- **阶段 C**：WeightLog 表 + /v1/weight-logs（照搬 WaterLog 幂等模式）；趋势图目标体重参考线；体脂率字段；断食期用餐标记
- **阶段 D**：health 包；iOS NSHealthShareUsageDescription + HealthKit capability；Android health 权限 + Play 健康数据声明；explicit consent 组件（合规 §2 规格）；读步数/活动能量/体重，写入消耗侧
- **阶段 E**：食物详情页重构（热量显著 + 三大营养素供能比例圆环 + 人话注释 + 其余折叠 + 红绿灯）；份量双轨
