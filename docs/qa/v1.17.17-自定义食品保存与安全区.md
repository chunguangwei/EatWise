# v1.17.17 自定义食品保存与安全区

## 取证与范围

用户截图：添加自定义食物标题与 Android 状态栏时间重叠，AI 估算后保存报错；截图未包含具体报错。

- 添加/纠错/编辑入口原本未传 useSafeArea，showModalBottomSheet 默认移除顶部 padding，内部 SafeArea 无法恢复。嵌套导航又使弹层停在底部 Tab 上方。三入口统一 root navigator + useSafeArea。
- 保存状态原本直接修改 _saving，不触发重建；改为 setState 与 BusyFilledButton，提交中锁定表单点击。
- 原保存只捕获 ApiException，非 API 异常逃逸；SnackBar 位于底层 Scaffold，可能被弹层遮挡。改为弹层底部可见错误与通用异常兜底，保留表单内容。
- 未修改营养判定规则、服务端、数据库结构、网络和证书。截图中 20 kcal / 1.2g 蛋白 / 25g 碳水 / 0.3g 脂肪虽已被标记存疑，但都在现有合法范围内；不能把数值不一致认定为保存失败根因，也不自动改写 AI 结果。
- 未取得用户具体错误文字，也未连接到生产服务器；本次修复明确复现的布局、忙态和异常可见性问题，不宣称已复现用户设备的具体保存异常。
