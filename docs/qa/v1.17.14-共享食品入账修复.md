# v1.17.14 共享食品入账修复

版本 1.17.14+144；问题反馈：分享食品点击确认后未记录，且看不到错误。

## 根因与修复

- RemoteFoodSearch 对贡献晋升食品保留 isCustom=true，却把 owner 清为 null。搜索返回未按 owner 过滤的行，列表可见，RecordRepository 事务读取时受隔离规则过滤而抛“食品不存在”。本人、旧坏缓存、同机切账号三例真实 SQLite 入账均复现失败；首次全新社区食品正常。
- 作者标记与 owner 成对保留；跨账号及 owner 为空的社区结果按服务端共享身份写入。数据库 beforeOpen 精确修复 source=community、owner NULL、isCustom=true 的元数据，兼容已在 v17 的旧库及离线启动，不改营养或记录、不增 schema。
- 共享食品遗留 customSyncPending 会让记餐 pushCount=0；已确认 community 来源绕过个人食品待上行守卫，其他来源保留保护。
- 网络搜索旧响应会覆盖在途编辑。缓存读写同事务保护当前 owner 的 dirty 草稿，并回读当前可见行，避免向 UI 返回等待前旧快照。
- 本地入账异常此前只显示滚动卡片内部错误，可能在视口外；现同时显示可见 SnackBar，保留输入及原行内提示，不抢新草稿焦点。

## 验证

- 增强真实页面保存失败回归，先确认缺少可见提示再修复。
