## 发布验证

候选版本已完成 slang/drift 生成、`dart format .`、`dart analyze`（零 issue）及 `flutter test`（1882 项全部通过）。生成后没有 schema 或额外生成文件变更。

## CI 历史问题复核

检查基线文档提交 ae2b3fa 的 CI（40818396817）发现 PostgreSQL 候选排序用例偶发失败（475 通过、1 失败）。测试给实体设置不同 createdAt，但生产 create 使用数据库默认时间；快速插入同毫秒后按随机 id 打破平局，测试却假定指定的时间已入库。仅修测试夹具：创建后显式设置持久 createdAt，再验证先入先审排序。没有修改服务端生产实现或接口。修正后隔离 PostgreSQL 全量 476 项及服务端 lint 通过。

## 验证边界
