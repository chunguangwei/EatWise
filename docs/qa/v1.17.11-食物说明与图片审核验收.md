# v1.17.11 食物说明与图片审核验收

日期：2026-10-26。版本：`1.17.11+141`。基线：`a229f1a`。

## 改动

- 食物详情移除单品红绿灯与折算步数，展示实际份量占当前每日摄入目标的比例；保留每 100g 营养与宏量供能比例。目标缺失、非法份量不展示虚构比例，合法零值与超过 100% 均如实展示。
- 数据来源只依据已存来源字段。内置库纠错通过不改为社区来源；自定义食品编辑将来源与营养同存，离线重试保留来源。已有 AI 食品仅改名称或别名仍保留估算标记，手改营养转为个人填写。
- 新图片帖进入既有人工审核队列，通过前仅作者可见；纯文字帖沿用直接公开。创建、队列和幂等回执同事务，审核、删除、举报、点赞和取消点赞共用帖子锁；既有已公开图片帖不追溯改变状态。
- 发布页解释图片审核、使用“提交审核”按钮、返回列表时提示仅自己可见。未公开帖向作者显示状态与审核/举报说明，缺失原因采用中性兜底，中英及大字体可换行。
- 同步 D-05/D-17 和隐私说明三处来源；未接入第三方图片审核供应商，不将人工队列描述成自动识别。
- 原生 QA 驱动使用显式独立包、本地 memory 服务及逐命令确认；连续输入命令不重新点击输入框。旧集成走查与网络探针增加本地环境门禁，避免向生产写演示数据。
