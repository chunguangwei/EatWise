# 《EatWise 模拟器全流程冒烟用例》v1.0

> 目的：在 Android 模拟器上完整走一遍产品主流程（P0 路径 + 各 Tab 核心功能）。
> 执行方式：adb 驱动（input tap / screencap / logcat），后端 `npm run start:dev`（内存库，验证码固定 123456），APK 用 `--dart-define=API_BASE_URL=http://10.0.2.2:3000/v1` 构建。
> 记录：每个检查点标记 ✅/❌ + 现象截图编号；❌ 项进入修复清单。
> 关联：docs/qa/ 两份用例文档（本表为真机执行浓缩版，D-xx 为决策编号）。

## A. 启动与合规

| # | 检查点 | 操作 | 预期 |
|---|--------|------|------|
| A1 | 首启隐私弹窗 | pm clear 后启动 | 弹窗出现：主同意必勾（按钮禁用态）+ 健康数据单独同意默认不勾 |
| A2 | 仅勾主同意 | 勾选①→继续 | 可进入登录页；健康数据未授权不阻断 |
| A3 | 协议链接 | 点隐私政策/用户协议 | 协议正文页打开，中英内容完整 |

## B. 登录与引导

## C. 首页断食计时（核心）

| # | 检查点 | 操作 | 预期 |
|---|--------|------|------|
| C1 | 状态环 | 查看首页 | 圆环 + 48px 倒计时 + 状态文案（断食中/进食中符合当前时间） |
| C2 | 归属日 | 查看环下文案 | 「本次断食计入 X 月 X 日」（D-07） |
| C3 | 结束断食 | 点「结束断食」 | 切换进食态（橙弧），记录实际时长 |
| C4 | 延长 | 点「延长」 | 进食窗口后移 30min（D-10），倒计时重算 |
| C5 | mini 信号卡 | 首页底部三卡 | 蛋白/碳水/热量显示，无数据走空态不误导 |

## D. 记录（最高频路径）

| # | 检查点 | 操作 | 预期 |
|---|--------|------|------|
| D1 | 搜索 | 记录 Tab 搜「米饭」 | 双语食物库命中（米饭/糙米饭等） |
| D2 | 结果卡 | 点选米饭 | 结果卡显示份量/营养，份量可编辑且营养实时重算 |
| D3 | 确认入账 | 点「确认记录」 | 乐观更新 +「已记录·撤销」吐司 |
| D4 | 吐司消失 | 等待 11 秒 | 吐司自动消失（D-11，persist:false 回归点） |
| D5 | 撤销 | 再记一笔→10s 内点撤销 | 该笔撤回，计数回退 |
| D6 | 饮水 | 点 +200 | 累计 200/2000ml，吐司 10s 后消失 |
| D7 | 体重 | 体重卡输入 65.5 | 保存成功；同日重复记覆盖 |
| D8 | 常吃 | 点「常吃」入口 | 列出历史高频（D3 记录过的米饭） |
| D9 | 语音 | 点「语音记」 | 权限申请→ASR 或降级提示（模拟器无麦克风预期降级不崩） |
| D10 | 拍照 | 点「拍照记」 | 权限申请→识别 stub 降级为引导手动搜索（D-16） |
