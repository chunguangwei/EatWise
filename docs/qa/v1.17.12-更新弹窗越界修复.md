# v1.17.12 更新弹窗越界修复

日期：2026-10-26。版本：`1.17.12+142`。基线：`1a556ec`。

## 现场与根因

用户提供安卓截图：1.17.11 更新说明超出白色弹窗，底部操作遮挡正文。`UpdateDialog` 使用默认不可滚动的 `AlertDialog`，其 content 为完整长 Text 的 Column；内容按全文高度布局，超出有限屏幕，actions 又独立布局。现有测试说明只有一行，未覆盖真实弹窗路由和长文案。

## 修复范围

- 使用 AlertDialog 的受限滚动区域容纳标题和说明，按钮留在区域外，小屏大字体保留完整内容与可点击操作。
- 下载中和失败时展示当前状态，避免进度/错误被长说明推到屏外；下载中禁止返回或点遮罩关闭，避免界面消失而下载继续。
- 强制更新调起安装器后恢复操作入口；取消系统安装返回后可再次安装，继续保留强制更新限制。
- 1.17.11 GitHub Release 文案已精简为三条用户可读说明，更新接口已回读生效；测试统计保存在验收文档。后续自动说明去除裸 Markdown 标题符号。

## 验证与发布

- 初始 16 条布局/状态回归全部复现失败，含 RenderFlex 长内容越界；仅加滚动后 12 条布局通过，状态测试继续捕获进度不可见或路由提前关闭。
- 新增 21 条真实路由回归，涵盖中英、亮暗、320×568 / 360×640 / 640×360、两倍字、实际滚到末尾、正文与按钮几何分离、下载顶部/末尾起点、返回拦截和平台初始化异常。
- 增强强制更新回归：调起安装后恢复操作、禁止关闭、可第二次调起；先确认缺少按钮的失败，再验证修复。
- 更新相关专项 **57 项通过**。`dart format .` 完成，`dart analyze` 零 issue，App 全量 **1805 项通过**（新增 21 项）。
