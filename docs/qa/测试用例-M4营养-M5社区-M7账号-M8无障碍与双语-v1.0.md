## 〇、通用约定

### 0.1 优先级定义

| 优先级 | 含义 |
|--------|------|
| P0 | 阻塞上线，核心闭环 / 合规 / 硬性门槛（M8 全部为 P0） |
| P1 | 重要功能路径，上线前必须通过 |
| P2 | 边界与体验增强，可排期修复 |

### 0.2 通用前置条件

- 测试环境：Flutter 3.x 构建的 iOS / Android 双端包，连测试环境后端（NestJS + PostgreSQL + Redis）。
- 最低版本基线：iOS 15 / Android 8.0（API 26）（D-14）。
- 测试账号：账号 A（有历史数据：streak、记录、补签卡）、账号 B（全新注册）、账号 C（英文系统语言）。
- 信号灯判定基准：「当日累计摄入 ÷ 当日目标 × 100%」（D-05）。
- 边界值归属〔假设〕：区间端点重叠时按「就优原则」判定——端点值落入更优区间（如 85% 判绿不判黄，60% 判黄不判红）；百分比判定用精确值，UI 展示取整。
- 双端差异：用例未特别注明时 iOS / Android 均需执行；标注「iOS：/ Android：」的须分别验证。

## 一、M4 营养信号灯（D-04 / D-05，PRD M4）

### 1.1 判定规则表（D-05，开发可并行，上线前需营养侧书面背书）

| 营养素 | 绿（达标） | 黄（提醒） | 红（警示） |
|--------|-----------|-----------|-----------|
| 热量 | 85%–110% | 60%–85% 或 110%–130% | <60% 或 >130% |
| 蛋白质 | ≥90%（>150% 除外） | 70%–90% | <70%；>150%（提示过量） |
| 碳水 | 85%–115% | 65%–85% 或 115%–135% | <65% 或 >135% |
| 脂肪 | 80%–110% | 55%–80% 或 110%–130% | <55% 或 >130% |

- 三重编码硬性要求：颜色 + 图标 + 文字（🟢/🟡/🔴 图标 + 状态文字），绝不单靠颜色（PRD M8）。
- 一句话建议：规则模板库（营养素 × 落区 × 餐段），中英双语各一套（D-05）。
- 蛋白质 90%–150% 区间判定为绿〔假设：D-05 仅标注 >150% 标红，未对 90%–150% 单独分区〕。

### 1.4 M4 探索性测试要点

- 用极端目标值（兜底默认 1800/2200 kcal，D-04）与大份量记录构造 >999% 的百分比，检查 UI 数字溢出与灯色稳定性。
- 在记录页撤销最后一条记录（D-11 撤销窗 10 秒内）后立即回数据页，验证信号灯实时回落。
- 修改个人资料（体重/目标）触发 TDEE 重算（D-04 热配置）后，当日历史灯色是否按新目标重判——确认预期口径〔待外部确认：重算后历史日是否回溯重判〕。
- 单手操作下连续快速切换日期，观察异步加载竞态（旧日期数据闪现）。

## 二、M5 streak 与社区（D-12 / D-17，PRD M5）

### 2.1 streak 规则表（D-12）

| 项 | 规则 |
|----|------|
| 口径 | 唯一口径 = 当日断食打卡达标（D-08）；饮食记录**不进** streak |
| 记录天数 | 独立统计，仅展示、不进 streak |
| 中断 | 当日未达标 → 当前 streak 归零，弹窗告知规则 |
| 断签弹窗三态 | 可补签（7 天内且有卡）/ 已用尽（无卡）/ 已断签（超 7 天不可补） |
| 补签卡发放 | 每月 1 日发放 2 张，当月有效、月底清零 |
| 补签卡库存 | 上限 2 张，不累积 |
| 补签范围 | 仅可补最近 7 天内的断签日 |
| 里程碑 | 3 / 7 / 30 天触发徽章 + 庆祝动效 + 可分享图卡 |

- 补签成功后 streak 恢复并衔接（补签日视为达标日）〔假设：D-12 未逐字写明补签后 streak 数值恢复方式〕。
- 里程碑仅首次达成时触发一次〔假设〕；streak 中断后重新达成同一里程碑不重复发徽章。

### 2.2 streak 状态迁移表

| 当前状态 | 事件 | 下一状态 | 附带行为 |
|----------|------|----------|----------|
| streak = N（N≥0） | 当日断食达标（D-08） | streak = N+1 | 若 N+1 ∈ {3,7,30} → 触发里程碑徽章 + 动效 |
| streak = N | 当日未达标且日终结算 | streak = 0 | 弹断签弹窗（三态之一） |
| streak = 0（断签 ≤7 天且有卡） | 用户使用补签卡 | streak 恢复衔接 | 卡库存 −1 |
| streak = 0（断签 ≤7 天且无卡） | 打开断签弹窗 | streak = 0 | 展示「已用尽」态 + 下月发放提示 |
| streak = 0（断签 >7 天） | 打开断签弹窗 | streak = 0 | 展示「已断签」态，补签入口禁用 |

## 三、M7 账号与同步（D-13 / D-18 / D-20，PRD M7）

### 3.1 规则要点

- 登录方式（D-13）：手机号验证码（主）+ 微信登录 + Sign in with Apple（iOS 上架强制）。Android 端不提供 Apple 登录入口〔假设：D-13 仅要求 iOS 提供 Apple 登录〕；Google 登录 MVP 不做。
