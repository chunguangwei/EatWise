- 断食归属日、连胜与补签、营养规则均以决策记录和既有规格为准。
- 本次只修改记录编辑弹层与 Prisma 初始化，并补充对应回归测试。

## 2026-10-24 UI 与输入体验优化（v1.17.3 / 133）

- 数据页和报告页将数值、曲线、日期分区；按文字实测宽度避让，优先显示最新值；体重目标说明移出曲线区，保留目标虚线和既有统计口径。
- 营养卡片随系统字号减少列数，主数值不再省略；统一报告标题层级与分段控件材质。
- HomeShell 不再提前消耗键盘 inset，输入时隐藏底栏；独立 ScaffoldMessenger 使提示显示在页面键盘上方，保留撤销并提供关闭按钮。提示条仍是 Scaffold 叠加提示，不能宣称自动为所有表单预留空间；回归验证关闭后滚动到输入框可继续输入。
- 卡片增加轻渐变与柔和阴影，输入框使用独立填充色，弹层提高不透明度并支持拖动收起键盘；onMaterial 卡片仍不绘制底色或渐变，避免遮挡水波纹。
- pubspec.lock 与仓库规定的 Flutter 3.44.8 重新对齐（intl/meta 等五个 SDK 约束依赖），没有新增依赖。
- 验证：dart analyze 零问题；全量 flutter test 1499 项通过；Android/iOS 平台键盘模拟、小屏大字体、标签碰撞及浅深色组件预览。非真机视觉验收。
