# 代码与 UI 首轮走查（2026-10-21）

范围：基于 v1.17.1+131，阅读决策记录、协作指南与近期提交，重点审查记录编辑、异步弹层生命周期、服务端驱动初始化，并检查首页、记录、数据、社区、设置五个页面的测试渲染。

## 项目结构与约束

- Flutter 客户端按 feature 分层，Riverpod 管理状态，drift 保存本地记录，slang 生成中英文文案。
- NestJS 服务端通过 StoreDriver 切换内存和 Prisma/PostgreSQL；本次不改 API、数据库结构或业务规则。
- 断食归属日、连胜与补签、营养规则均以决策记录和既有规格为准。
- 本次只修改记录编辑弹层与 Prisma 初始化，并补充对应回归测试。

## 已修复问题

| 问题 | 触发与影响 | 修复与回归证据 |
